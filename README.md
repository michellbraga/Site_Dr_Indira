# Site da Dra. Indira M. Parra

Site institucional de uma página em HTML, CSS e JavaScript.

## Visualização local

Na pasta site-indira, execute node server.mjs e abra http://127.0.0.1:4178.

## Imagens

- background-medico.jpg: camada global fixa com o Bastão de Asclépio.
- dra-indira-hero.jpg e dra-indira-sobre.jpg: retratos oficiais integrados às composições do Hero e Sobre.
- consulta.jpg: fotografia editorial de atendimento na seção Abordagem.
- cta-atmosfera.jpg: textura visual do CTA final.

As imagens foram exportadas em JPEG otimizado para web. Os originais enviados foram mantidos na pasta de origem.

## Configuração antes de publicar

- Em script.js, substituir WHATSAPP_NUMBER pelo número internacional, apenas dígitos.
- Em script.js, substituir SITE_URL pelo domínio HTTPS final. Canonical e og:url são gerados quando configurado.
- Atualizar sitemap.xml com o domínio real.
- Confirmar o status atual e a previsão de conclusão da pós-graduação em Endocrinologia e Metabolismo.

O símbolo de Asclépio é um fundo estático global; a linha de progresso acompanha apenas a posição da rolagem. O mobile usa a mesma camada fixa com dimensões ajustadas à viewport.
